# Meridian blog

The blog runs on GHL's built-in Blogs feature (Sites > Blogs), which handles post URLs, the RSS feed and the sitemap. The `/blog` page in `src/pages/blog.html` wraps GHL's **Blog Post List** element with the Meridian header, hero and CTA.

## Setup in GHL

1. Sites > Blogs > create a blog called "Meridian", attached to the Meridian website, with categories **Google Reviews**, **Google Business Profile**, **Websites** and **Local Marketing**.
2. Blog settings: author "Marcus" with a short bio, and set the blog post template to use the Meridian header and footer global sections and the Inter font.
3. On `/blog`, place the Blog Post List element where `dist/ghl/pages/blog/README.txt` says.
4. For each post below: create a post, open the editor's HTML or code view and paste everything below the `<!--post ... -->` header. Then fill in the SEO title, description, slug, category and a featured image (1200x630, a real photo or a simple branded graphic) from that header.
5. Check the post URL GHL gives the first post (usually `/post/<slug>`). If it isn't `/blog/<slug>`, update the one link between posts in `rank-higher-on-google-maps.html`.

## Content plan

The aim is one post a week for the first three months, then two a month. Each post targets one search, links to the service page it supports, and ends with a call to book. Trade-specific posts ("for plumbers", "for cleaners") are worth the most, because they match how owners actually search.

## Writing rules

- Australian spelling, plain English, short paragraphs, one H1 (the post title) and descriptive H2s.
- No invented statistics. Cite Google, the ACCC or the OAIC directly when you quote rules or numbers.
- Every post links to at least one service page and ends with a call to book.
